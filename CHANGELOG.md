# Changelog

All notable changes to this project will be documented in this file. The Python and npm packages always share the same version.

From 0.8.0, entries are generated by [release-please](https://github.com/googleapis/release-please) from pull request titles. To change the wording of an entry, edit it in the Release PR before merging. See [Publishing](/README.md#publishing) in the README.

This project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html). Entries up to 0.7.0 were written by hand in the [Keep a Changelog](https://keepachangelog.com/en/1.0.0/) format.
